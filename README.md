# <h1 align="center">Init OS</h1>

自从接触编程以来，就对操作系统十分感兴趣。

各种各样的操作系统运行在成千上万的设备上，早已经融入到生活的方方面面，自己写一个操作系统是一件十分酷的事情。

InitOS是一个简单的微内核操作系统，将会提供简单的图形界面，几个简单的应用。
